# Reference

Osama, M., Merrill, D., Cecka, C., Garland, M., Owens, J. D.
**"Stream-K: Work-centric Parallel Decomposition for Dense Matrix-Matrix
Multiplication on the GPU."** arXiv:2301.03598, 2023.
https://arxiv.org/abs/2301.03598

This sandbox's network can't reach arxiv.org directly to save the PDF
here automatically (allowlist blocks it, same as IEEE/ACM were
blocked). Download it yourself from the link above and drop the PDF
in this folder before pushing to GitHub — it's open access, no
paywall, just needs a human click.

See `../NOTES_streamk_paper.md` for the methodology notes pulled from
the paper (work-splitting formula, fixup/ownership rule, hybrid
variant) that `hybrid_coordinator.py` is built from.
